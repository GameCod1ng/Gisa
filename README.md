# 정보처리기사 실기 문제은행 (PWA)

오프라인에서 동작하는 자가채점 문제은행입니다. 홈 화면에 설치하면 앱처럼 실행됩니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 본체 (화면·파서·채점·통계 전부 여기에) |
| `manifest.json` | 앱 이름, 아이콘, 실행 방식 |
| `sw.js` | 서비스워커 — 오프라인 실행을 담당 |
| `icon-192.png` / `icon-512.png` | 앱 아이콘 |
| `icon-maskable-512.png` | 안드로이드 적응형 아이콘 |
| `apple-touch-icon.png` | 아이폰 홈 화면 아이콘 |

7개 파일을 **같은 폴더에 평평하게** 두어야 합니다. 하위 폴더로 나누면 경로가 어긋납니다.

## GitHub Pages에 올리기

1. GitHub에서 새 저장소를 만듭니다. 이름은 `gisa` 등 아무거나, **Public**으로 둡니다.
2. 저장소 첫 화면에서 `uploading an existing file` 링크를 누릅니다.
3. 위 7개 파일을 **한꺼번에 끌어다 놓고** `Commit changes`를 누릅니다.
4. `Settings` → 왼쪽 메뉴 `Pages` → Source를 `Deploy from a branch`, Branch를 `main` / `/ (root)`로 두고 저장합니다.
5. 1~2분 뒤 `https://<아이디>.github.io/gisa/` 주소가 살아납니다.

Public 저장소면 소스가 공개됩니다. 문제 데이터는 업로드하지 않으니 기출 내용이 노출되지는 않습니다.

## 폰에 설치하기

**안드로이드 (Chrome)** — 주소를 열면 설치 배너가 뜹니다. 안 뜨면 우측 상단 `⋮` → `앱 설치`.

**아이폰 (Safari 필수)** — 공유 버튼 `↑` → `홈 화면에 추가`. Chrome이나 카톡 내부 브라우저에서는 메뉴가 나오지 않습니다.

설치 후 한 번 열어두면 앱 파일이 캐시에 저장되어 그다음부터는 비행기 모드에서도 열립니다.

## 데이터 보관

문제와 회독 기록은 **그 기기의 브라우저 안에만** 저장됩니다. 서버로 나가지 않습니다.

- 기기 간 동기화는 되지 않습니다. PC와 폰은 각각 따로 쌓입니다.
- 문제관리 탭 → `파일로 저장`으로 JSON을 내려받아 백업하고, 다른 기기에서 `파일 불러오기`로 옮기세요. 같은 문제는 중복으로 들어가지 않습니다.
- 브라우저 저장소를 비우면 데이터가 사라지니, 문제를 많이 넣은 뒤에는 한 번 내려받아 두는 편이 안전합니다.

## 앱을 수정했을 때

`index.html`을 고쳐서 다시 올려도, 서비스워커가 예전 파일을 캐시에서 꺼내 쓰기 때문에 화면이 그대로일 수 있습니다.

`sw.js` 첫 줄의 버전을 올려주세요.

```js
const VERSION = 'gisa-v1';   // → 'gisa-v2'
```

이 값이 바뀌면 예전 캐시를 지우고 새 파일을 받아옵니다.

## 붙여넣기 형식

문제 사이를 `---` 로 구분합니다.

```
[데이터베이스] 정규화에서 부분 함수 종속을 제거하는 단계는?
답: 제2정규형(2NF)
해설: 1NF에서 부분 함수 종속을 제거하면 2NF가 된다.
---
[네트워크] OSI 7계층 중 라우팅을 담당하는 계층은?
1) 데이터링크 계층
2) 네트워크 계층
3) 전송 계층
4) 세션 계층
답: 2
```

- `[대괄호]` 는 분류입니다.
- `답:` `해설:` `분류:` 로 시작하는 줄은 각각 그 항목으로 들어갑니다.
- `1)` `2)` 로 시작하는 줄이 2개 이상이면 객관식으로 인식하고, `답: 2` 는 두 번째 보기를 뜻합니다.
- 백틱 세 개로 감싼 부분은 코드 블록으로 표시됩니다.
